# מערכת ניהול קשרים – מכון משפטי ארץ (גרסה 1)

גרסה ראשונה: **CRM + שו"ת**. השתלמויות, ספרים ו-Webhook של Jgive יתווספו בשלבים הבאים.

## מה יש בתיקייה

| קובץ | מה זה |
| --- | --- |
| `index.html` | מערכת הצוות (כניסה עם סיסמה) |
| `ask.html` | טופס "שאל את הרב" לציבור – לקשר מהאתר |
| `shut.html` | מאגר שו"ת ציבורי (שאלות שהרב סימן לפרסום) |
| `js/config.js` | **הקובץ היחיד שצריך לערוך** – פרטי Firebase ונושאי שאלות |
| `firestore.rules` | חוקי אבטחה למסד הנתונים |

## הקמה (פעם אחת, כ-20 דקות)

1. **פרויקט Firebase**: נכנסים ל-console.firebase.google.com ← Add project. אפשר בלי Google Analytics.
2. **מסד נתונים**: Build ← Firestore Database ← Create database ← Production mode ← מיקום `eur3` (אירופה).
3. **חוקי אבטחה**: בלשונית Rules מוחקים הכול, מדביקים את תוכן `firestore.rules`, ולוחצים Publish.
4. **כניסה עם Google**: Build ← Authentication ← Get started ← Sign-in method ← Google ← Enable ← בוחרים מייל תמיכה ← Save.
5. **חיבור האתר**: ⚙️ Project settings ← Your apps ← סמל `</>` ← נותנים שם ← מעתיקים את `firebaseConfig` לקובץ `js/config.js`.
6. **GitHub**: מעלים את כל התיקייה למאגר חדש ← Settings ← Pages ← Branch: main ← Save.
7. **דומיין מורשה**: ב-Firebase ← Authentication ← Settings ← Authorized domains ← מוסיפים `שם-המשתמש.github.io`.
8. **מנהל ראשון** (פעם אחת, ידנית): ב-Firebase ← Firestore Database ← Data ← Start collection. Collection ID: `allowedEmails`. Document ID: כתובת ה-Gmail שלך באותיות קטנות. מוסיפים שדה `role` מסוג string עם הערך `admin`, ושדה `name` עם השם שלך ← Save. נכנסים לאתר עם אותו חשבון Google.
9. מעכשיו המנהל מוסיף עובדים בלשונית **משתמשים**: כתובת Google, שם ותפקיד. רק כתובות מהרשימה יכולות להיכנס, והסרה מהרשימה חוסמת את הגישה מיד.

## תפקידים

| תפקיד | גישה |
| --- | --- |
| מנהל מערכת (`admin`) | הכול, כולל משתמשים ומחיקת אנשי קשר |
| רכז הרכזים (`head`) | אנשי קשר, שו"ת, ייבוא, מבט על כל הרבנים |
| צוות (`staff`) | אנשי קשר, שו"ת, ייבוא |
| רב משיב (`rabbi`) | שו"ת, תקציר על השואל, צפייה בלבד בכרטיסים |

## שימוש יומיומי

- **ייבוא נתונים קיימים**: לשונית ייבוא ← קובץ Excel/CSV ← בוחרים מה הוא מכיל (תרומות, השתלמות, ספרים) ← בודקים התאמת עמודות ← ייבוא. אנשים קיימים מזוהים לפי מייל או טלפון.
- **תרומות מ-Jgive**: בשלב זה מייצאים דוח תרומות מ-Jgive ומייבאים אותו כ"תרומה".
- **חיתוך ושליפה**: באנשי קשר מוסיפים "תנאי היסטוריה" – למשל *יש לו* תרומה, *אין לו* רכישת ספרים שמכיל "שמיטה". שומרים כרשימה, מייצאים ל-Excel או מעתיקים מיילים (רק מאשרי דיוור).
- **שאלות שהגיעו במייל**: בשו"ת ← "שאלה ידנית".
- **פרסום שאלה במאגר**: בתוך השאלה ← "פרסום במאגר" ← עורכים את נוסח השאלה בלי פרטים מזהים.

## הערות

- נושאי השאלות ב-`js/config.js` הם הצעה ראשונית – כדאי לעדכן לפי הצורך.
- המערכת טוענת את כל אנשי הקשר לדפדפן. זה מתאים לעשרות אלפי רשומות. בהיקף גדול יותר נעבור לשליפה חלקית.
- התוכנית החינמית של Firebase (Spark) מספיקה לגרסה הזו. חיבור Webhook אוטומטי מ-Jgive ידרוש Cloud Function ומעבר לתוכנית Blaze (תשלום לפי שימוש, בדרך כלל אפסי בהיקף כזה).
